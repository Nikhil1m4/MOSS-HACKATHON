# BrandAid 
## Connecting Brands and Customers

This was an incomplete hackathon project that my team and I initiated while participating in our university's Programming Club hackathon. I have the source code and am currently working on making it functional.

## What This System Does

It works like a technician who helps customers repair minor problems on their own. This technician is trained using user modules provided by companies.

Initially, I plan to complete it for one brand, but later I will add a multi-brand functionality.
